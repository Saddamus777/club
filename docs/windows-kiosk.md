# Подготовка ограничений Windows 11 Pro

Редакция игровых ПК подтверждена пользователем: Windows 11 Pro. Assigned Access
доступен в Pro; для нашего WinForms-клиента исследуется режим ограниченного рабочего
стола с несколькими разрешёнными приложениями. Основание:
[документация Microsoft](https://learn.microsoft.com/en-us/windows/configuration/assigned-access/).

**Сейчас реализованы экспорт черновика и предварительная проверка, а не применение
или доказанная защита рабочего места.** Даже после установки статического списка
разрешённых EXE остаётся задача запрета запуска этих EXE вне оплаченного сеанса.
Отображение таймера и кнопка запуска эту задачу не решают.

## Что можно выполнить сейчас

На игровом ПК с установленным агентом и настроенным каталогом, в 64-разрядном
PowerShell администратора из распакованного комплекта:

```powershell
.\Setup\Export-KioskDraft.ps1 -OutputDirectory .\kiosk-trial-01
```

Папка должна быть новой. Скрипт получает посетителя по SID из installation.json;
для администратора Windows экспорт запрещён. Проверяет каталог реальным Agent EXE,
собирает отчёт об ОС, редакции Pro, UAC, включённой локальной учётной записи,
службе LocalSystem/Automatic/Running и включённом задании автозапуска с ограниченными
правами. Отчёт не содержит ключа устройства, пароля, сертификата или аргументов игр.
Он содержит имя Windows-пользователя и SID: не публиковать его без необходимости.

Создаются:

- `assigned-access.draft.xml`: одна учётная запись, Visitor с автозапуском и точные
  пути EXE из каталога. Дубли путей убираются; аргументы и маски не переносятся.
  Пустой каталог оставляет только Visitor. Меню закреплённых приложений пустое,
  панель задач видимая. Это предложение для испытания, не проверенная конфигурация игр.
- `readiness.json`: результаты каждой предварительной проверки, список дальнейших
  работ, `policyApplied: false` и `readyForOperation: false`.

`setupPrerequisitesPassed` означает только прохождение перечисленных проверок.
Технический порог версии — Windows 11 22H2 (build 22621) для схемы 2022; это **не**
проверка срока поддержки Windows или наличия нужных накопительных обновлений.
Для испытания нужна поддерживаемая, полностью обновлённая Windows 11 Pro.
На Server отчёт укажет несоответствие даже при успешном экспорте XML.

Ни GPO/AppLocker/CSP, ни реестр, служба, задание и учётные записи не меняются.
Отмена экспорта — удаление созданной папки. Uninstall-Agent также не применяет
и не удаляет сторонние политики.

## До отдельного испытания применения

1. Подготовить один тестовый ПК, резервную копию и отдельный проверенный вход
   администратора Windows. Не использовать рабочий сеанс посетителя или реальные деньги.
2. Проверить имеющиеся Assigned Access, Shell Launcher, AppLocker, GPO/MDM.
   Экспортёр не читает их эффективное состояние и не подтверждает отсутствие конфликтов.
   Сохранить исходное состояние; не заменять чужие политики этим черновиком.
3. Проверить эффективные права посетителя на EXE, DLL и родительские каталоги.
   Посетитель не должен подменять разрешённые программы. Каталог может содержать
   универсальные интерпретаторы/лаунчеры; генератор не анализирует их поведение.
   Проверить дочерние EXE, службы античита, обновления, Steam и браузеры отдельно.
4. Сверить XML с [актуальной схемой Microsoft](https://learn.microsoft.com/en-us/windows/configuration/assigned-access/xsd).
   Текущие автоматические проверки проверяют структуру и область профиля, а не
   принятие CSP или соответствие полной XSD. Добавлять только конкретные необходимые
   зависимости. Профиль не синхронизируется при последующем изменении games.json.
5. Отдельно реализовать и проверить запрет неоплаченного доступа и очистку чужих
   входов. До этого профиль не предназначен для эксплуатации клуба.

В [официальной процедуре применения и удаления](https://learn.microsoft.com/en-us/windows/configuration/assigned-access/configure-multi-app-kiosk)
описан MDM Bridge WMI Provider. Устройство настраивается из контекста SYSTEM;
обычный PowerShell администратора не равнозначен SYSTEM. Применение действует при
следующем входе пользователя. Удаление Configuration не восстанавливает все изменения,
например оформление меню «Пуск». Поэтому автоматическое применение/откат в установщик
пока не добавлены: они требуют отдельной проверки на Windows 11 Pro и сохранённого
исходного состояния. Некоторые настройки Assigned Access затрагивают и другие аккаунты.

## Матрица будущей проверки Windows 11 Pro

Фиксировать версию ОС/обновлений/комплекта, исходные политики, ожидаемый и фактический
результаты. Windows Server CI не заменяет эту матрицу.

| Проверка | Что подтвердить |
|---|---|
| Вход посетителя | Один Visitor, работа регистрации/покупки, отсутствие административных прав |
| Вход сотрудника | Сохраняется вход и доступ к восстановлению; сторонние аккаунты проверены отдельно |
| Запуск/зависимости | Реальные игры, браузер, античит и обновления работают в разрешённом сеансе |
| Обходы | Проводник, диалоги открытия файлов, консоли, ярлыки, URI, сменные носители, закрытие Visitor |
| Неоплаченный доступ | Разрешённую игру нельзя запустить напрямую до покупки, после окончания или при Recovery |
| Сбой/перезапуск | Служба контролирует время; после сбоя нельзя получить доступ бесплатно |
| Откат | Удаляется только испытательная политика; проверяются оставшиеся изменения профиля и вход сотрудника |
| Смена посетителя | Не остаются аккаунты Steam/браузера, cookies и пользовательские файлы предыдущего клиента |
