## Известные границы реализации

- Свободное место не защищено kiosk-политикой; очистка сохранённых аккаунтов отсутствует.
  Выход из Windows не удаляет токены Steam/браузера. Каталог ограничивает штатный запуск
  через Visitor, но не запуск программ в обход него.
- Нет автоматической установки обновлений/обновления сертификата или подписи EXE.
- Закрытый Visitor не покажет предупреждение; служба продолжает таймер независимо от него.
- Статус/остаток администратора — последнее подтверждение. Без LAN пауза остаётся ожидающей;
  принудительный обход подтверждения для возврата не предусмотрен.
- Сон/гибернация, сохранение остатка при физическом сбое и защита от обходов требуют
  отдельного испытания. Последний интервал записи может потеряться при аварии накопителя.
- Приложение администратора ещё не содержит все вспомогательные функции веб-прототипа.
- Нет испытания 30 физических ПК. Реальные деньги и развёртывание клуба не разрешаются
  этим отчётом. Следующий шаг — [матрица испытаний одного ПК](windows-pilot.md).

## Исправление первого запуска после сообщения пользователя

Пользователь сообщил `'удалось' is not recognized` при запуске CMD и экран с подсказкой
`--create-owner`. В первом комплекте были LF и кириллица в командных файлах. Подтверждено
наличие обоих факторов; выполнение cmd.exe в Linux не проверялось.

Сборщик теперь принудительно пишет ASCII/CRLF и проверяет эти свойства для каждого CMD.
Добавлен `00-start.cmd`; сервер открывает браузер после готовности на Windows.
Владелец создаётся в браузере при работающем сервере, без конфликта отдельного процесса
с блокировкой базы. Существующие данные и формат базы не меняются.
ZIP содержит `VERSION.txt` с версией 0.1.1. Новая Windows-проверка всё ещё требуется.

Тестовые базы и случайные пароли браузерной проверки удалены после её завершения.
В поставке нет стандартного пароля, демонстрационного владельца или финансовых данных.
