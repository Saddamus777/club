# Результаты проверки прототипа 0.1.1

Дата: 23 октября 2026. Среда проверки: Linux x86_64, .NET SDK 10.0.402 / runtime 10.0.13.
Это результаты текущего экземпляра среды, не подтверждение работы на компьютерах клуба.

## Пройдено

- `bash scripts/setup-cloud.sh`: повторная установка с проверкой существующего SDK,
  locked restore .NET и npm ci, Release-сборка — 0 ошибок, 0 предупреждений.
- `dotnet test`: **23 пройдено, 0 провалено, 0 пропущено**.
  Проверены атомарная покупка и повтор запросов; нехватка средств; конкурирующие покупки;
  ограничение одного места/посетителя; пауза/возобновление; истечение времени;
  перезапуск и скачок часов; ручной возврат без повторного зачисления;
  неизменность купленного пакета при редактировании тарифа; полномочия и приватность;
  бесплатное время; полная копия/восстановление и отказ при несогласованном балансе;
  видимость активных сеансов при длинной истории;
  HTTP-сценарий с cookies/CSRF и ограничением попыток входа; первичная настройка
  владельца, запрет повторной настройки и запросов не с loopback, CSRF и подтверждение
  пароля, конкурирующие запросы первого запуска (создаётся ровно один владелец).
- Реальный Chromium через Playwright: создание владельца через форму на пустой базе
  без консольной команды, отказ при разных паролях, автоматический вход и перезагрузка
  страницы; регистрация и вход под двумя изолированными
  аккаунтами; создание места/пакета; пополнение с искусственной потерей ответа после
  записи на сервере, затем безопасный повтор; покупка; пауза и возобновление;
  остановка и повторный запуск процесса сервера; ручной возврат; проверка цифр отчёта;
  скачивание и проверка SQLite-копии. Ошибок выполнения JavaScript не обнаружено.
- Проверены снимки интерфейса на широком экране и ширине 390 px; горизонтального
  переполнения страницы нет. Таблицы/навигация допускают внутреннюю прокрутку.
- Кросс-сборка Windows x64 с включённым runtime, архив ZIP и SHA-256.
  Контрольная сумма находится рядом с архивом; архив не содержит пользовательской базы.

## Исправление первого запуска после сообщения пользователя

Пользователь сообщил `'удалось' is not recognized` при запуске CMD и экран с подсказкой
`--create-owner`. В первом комплекте были LF и кириллица в командных файлах. Подтверждено
наличие обоих факторов; выполнение cmd.exe в Linux не проверялось.

Сборщик теперь принудительно пишет ASCII/CRLF и проверяет эти свойства для каждого CMD.
Добавлен `00-start.cmd`; сервер открывает браузер после готовности на Windows.
Владелец создаётся в браузере при работающем сервере, без конфликта отдельного процесса
с блокировкой базы. Существующие данные и формат базы не меняются.
ZIP содержит `VERSION.txt` с версией 0.1.1. Новая Windows-проверка всё ещё требуется.

Тестовые базы и случайные пароли браузерной проверки удалены после её завершения.
В поставке нет стандартного пароля, демонстрационного владельца или финансовых данных.

## Не проверено и не реализовано

- Запуск `.exe` и `.cmd` на реальной Windows 11. Требуется первый тест по `windows-test.md`.
- Установка службы, блокировка Windows, завершение игр, очистка чужих аккаунтов,
  автономный клиентский таймер при потере LAN — ещё не реализованы.
- Реальное отключение питания, UPS, обрыв LAN, отказ/заполнение диска, 30 физических ПК.
- Полноценная работа со сменами и закрытие кассы, сложные акции и эксплуатационная безопасность.
- Подпись Windows-комплекта и защищённое шифрование локальных копий.
- Публикация облачной среды и восстановление в новой задаче не проверялись.

## Воспроизведение

```bash
cd /workspace/club
bash scripts/setup-cloud.sh
bash scripts/dotnet.sh test Club.slnx -c Release --no-restore
# Перед следующим шагом остановить свой сервер на порту 5080.
CLUB_PACKAGED_CHROMIUM=1 node tests/browser/smoke.cjs
bash scripts/publish-windows.sh
```

В sandbox .NET может потребовать расширенного запуска для служебных mutex-файлов
в профиле пользователя. Проверки TLS, SHA-512 SDK и целостности пакетов не отключались.
Обычный Playwright CDN оказался недоступен по сетевой политике; проверка выполняется
на закреплённом Chromium из npm-пакета с проверкой целостности через lockfile.
