# Испытание Windows / LAN, версия 0.2.0-pilot

Это промежуточная реализация этапа 0.2, **не готовая система клуба**.
Сначала один игровой ПК, учебный баланс и сохранённые игровые файлы.
Состояние проверок и ограничения: [validation.md](validation.md).

## Состав комплекта

- `Admin/Club.Admin.exe` — отдельное нативное приложение сотрудника (WinForms).
  Создание владельца, места/тарифа, пополнение, бесплатное время, пауза/возобновление/
  завершение, возврат, привязка устройства, отчёт и журнал.
- `Server/Club.Server.exe` — ASP.NET Core / SQLite на ПК администратора.
  При запуске Admin автоматически запускает соседний Server, если порт 5080 свободен.
  Закрытие Admin не останавливает сервер. Остановка сервера — Ctrl+C в его окне.
- `Visitor/Club.Visitor.exe` — отдельное нативное приложение посетителя: регистрация,
  вход, баланс, пакеты, покупка для своего ПК, таймер и предупреждение за 5 минут.
- `Agent/Club.Agent.exe` — Windows-служба `ClubAgent` от LocalSystem, установленная
  на игровой ПК. Хранит ключ устройства и остаток; обращается к серверу по HTTPS.
  UI подключается к ней через локальный named pipe, доступный указанному Windows SID.
- `Setup/*.ps1` — явная настройка LAN, установка/удаление службы и отключение LAN.

.NET включён в сборки win-x64. Отдельный SDK не требуется. Программы и скрипты пока
не подписаны. Не отключайте Defender/SmartScreen и не меняйте ExecutionPolicy для
обхода блокировки; сохраните сообщение для разбора.

## Что пока отсутствует

Автоматический запуск Visitor при входе, kiosk/Assigned Access, защита от запуска
произвольных программ в свободном состоянии, каталог/запуск игр, удаление игровых
и браузерных профилей, полноценный установщик/обновление/подпись, смены и касса,
редактирование тарифов и управление сотрудниками в новом окне (пока есть в локальном
веб-интерфейсе). Нет гарантии предупреждения, если окно Visitor закрыто.

**Выход из Windows закрывает процессы, но не удаляет сохранённые токены Steam,
браузера и других аккаунтов. Свободное место после выхода не защищено kiosk-политикой.**
Не допускать посетителей к этому комплекту до завершения этих работ и испытаний.
Во время паузы служба завершает Windows-сеанс выделенного посетителя и запрещает
ему оставаться вошедшим до возобновления. Несохранённые данные приложений могут пропасть.

## ПК администратора

1. Остановить предыдущий сервер, сделать проверенную копию базы. Распаковать комплект
   в отдельную папку. Для переноса данных скопировать старую `.data` в `Server/.data`
   **при остановленных обоих серверах**. Никогда не копировать живую SQLite как обычный файл.
2. Запустить `Admin/Club.Admin.exe`. На пустой базе — «Создать владельца», затем «Войти».
   Логин/пароль выбирает владелец, стандартного пароля нет.
3. Создать место и пакет. Суммы в новом окне пока вводятся **в тыйынах**: 10 000 = 100 сом.
4. Закрепить IPv4 адрес ПК администратора, например `192.168.1.10`. Проверить, что это
   адрес данного ПК, сетевой профиль — Private, доступ нужен только из сети клуба.
5. Из PowerShell с правами администратора, в папке комплекта:

   ```powershell
   .\Setup\Enable-Lan.ps1 -ServerAddress 192.168.1.10
   ```

   Скрипт создаёт TLS-сертификат для указанного IP на шесть месяцев, защищает `.data`
   и файл TLS-настроек ACL, добавляет правило входящего TCP 5443 только для Private /
   LocalSubnet. Порт 5080 остаётся loopback. Сохранить показанный отпечаток сертификата.
   Перезапустить Server. Для этих настроек используется стандартное окружение Production.
6. Выбрать место, нажать «Привязать ПК», сохранить `PC.binding.json`. Файл содержит
   секрет конкретного ПК, не отправлять его в GitHub/чат и не оставлять в общей папке.
   Ключ сохраняется на сервере только как SHA-256. Привязка запрещена, если есть
   незакрытый или неподтверждённый сеанс. Повторная привязка свободного ПК меняет ключ.
   Если ответ потерян, в локальном веб-интерфейсе операции с устройствами пока нет:
   повторить отправку сохранённого JSON на `/api/admin/devices` с тем же operationId
   через авторизованный локальный API либо заново привязать свободное место новым ключом.

## Игровой ПК

1. Подготовить отдельного **локального стандартного пользователя Windows**, например
   `ClubVisitor`, с паролем. Не использовать Windows-аккаунт сотрудника. Автовход не включается.
2. Передать комплект, файл привязки и **только публичный** `Setup/club-server.cer`.
   Сверить отпечаток по экрану ПК администратора, а не доверять файлу из неизвестного источника.
3. В PowerShell с правами администратора:

   ```powershell
   .\Setup\Install-Agent.ps1 -BindingFile .\PC.binding.json `
     -ServerUrl https://192.168.1.10:5443 -VisitorUser ClubVisitor `
     -ServerCertificate .\club-server.cer -CertificateThumbprint ОТПЕЧАТОК_С_ПК_АДМИНИСТРАТОРА
   ```

   Скрипт устанавливает файлы в `%ProgramFiles%\Club`, секрет/остаток в
   `%ProgramData%\Club\Agent` с доступом только SYSTEM и администраторам. Добавляет
   доверие ровно проверенному сертификату, создаёт службу и настраивает её перезапуск.
   Входящих сетевых портов на игровом ПК не открывает. Удалить транспортную копию привязки.
4. Войти в Windows как `ClubVisitor`, запустить
   `C:\Program Files\Club\Visitor\Club.Visitor.exe`, зарегистрироваться в клубе.
   На ПК администратора выбрать посетителя, пополнить учебный баланс. На игровом ПК
   купить пакет. Выбор другого места не предлагается: служба подставляет свою привязку.
5. Сверить номер команды и подтверждения в таблице сеансов. Пока они отличаются,
   команда ещё не подтверждена службой. Время на сервере — последнее подтверждённое;
   во время разрыва связи оно может отставать от локального таймера.

## Обязательный журнал испытаний

Для каждого пункта записывать версии Windows/комплекта, ожидаемое/фактическое поведение,
остаток/баланс до и после, точные ошибки, время и результат. Без этих результатов этап 0.2
не завершён. Для CI достаточно запуска окон; следующая матрица выполняется на тестовом ПК.

| Сценарий | Ожидается |
|---|---|
| Повтор покупки после потери ответа | Прежний operationId; одно списание |
| Чужой ключ / другая привязка / недоверенный TLS | Отказ, без покупки и без отключения проверки TLS |
| Пауза / продолжение | Выход только ClubVisitor; таймер сохранён; продолжение после подтверждения ПК |
| Предупреждение / окончание | За 5 мин видимое сообщение; по нулю выход ClubVisitor, закрытие тестовых игры и браузера |
| Закрытие Visitor | Служба и таймер продолжаются, окончание с выходом; отсутствие предупреждения фиксируется как ограничение |
| Обрыв только интернета | Не влияет на LAN и оплаченный сеанс |
| Обрыв LAN | Остаток идёт локально, новые операции не проходят; окончание работает без сервера |
| Завершение сотрудником при обрыве | Команда ожидает; возврат и повторное занятие места/аккаунта запрещены |
| Возврат LAN после окончания | Реальный остаток сверяется; никаких повторных денег/времени |
| Перезапуск сервера | На возвращении связи пауза, минимум серверного/локального остатка |
| Перезапуск службы / питание ПК | Сохранённый остаток, Recovery/Paused, продолжение только сотрудником |
| Сбой/заполнение диска | Не подтверждать команду без записи; выход посетителя/остановка службы, восстановление по журналу |
| Параллельный Windows-сеанс сотрудника | Никогда не завершается: проверяется SID |
| Повторный вход после истечения | Проверить известный пробел свободного состояния; эксплуатация запрещена до kiosk |
| Резервная копия v1 / v2 | Восстановление в отдельной папке; миграция; те же балансы; активные сеансы приостановлены |
| Удаление службы / отключение LAN | Удаляются только созданные компоненты, данные сохранены |

Остаток сохраняется примерно каждые 250 мс через flush и замену файла. Это не гарантия
нулевой потери при сбое накопителя. Сон/гибернация и физическое выключение требуют
отдельного измерения; sleep не равен перезапуску процесса.

## Откат

Сначала завершить сеансы, дождаться подтверждений и сохранить базу/журнал. На игровом ПК:

```powershell
.\Setup\Uninstall-Agent.ps1
```

Удаляются только служба и доверие сертификату, добавленное этим установщиком. Конфигурация,
остаток и файлы остаются для разбора; повторная установка откажет, пока администратор явно
не архивирует прежние данные. Shell/автовход/GPO не менялись.
На ПК администратора: `Setup/Disable-Lan.ps1`, затем перезапустить Server.
Старый прототип 0.1 не понимает схему v2: для отката программы потребуется сохранённая
копия v1 с обязательным учётом операций, сделанных после неё. Не подменять базу без сверки денег.
