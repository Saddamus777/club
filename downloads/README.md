# Готовый комплект Windows

[Скачать ZIP](https://github.com/Saddamus777/club/blob/main/downloads/club-prototype-0.1-win-x64.zip?raw=true)

Это локальный прототип 0.1.1 для Windows 11 x64, с включённым .NET runtime.
Не требуется VS Code или самостоятельная сборка. В архиве есть `READ-ME.md` и команды:

1. `00-start.cmd` — запустить сервер и открыть браузер, оставить окно сервера открытым.
2. На странице первого запуска создать владельца со своим логином и паролем.
3. Если браузер не открылся автоматически, использовать `03-open.cmd`.

В этой версии исправлены переносы строк командных файлов Windows; русские сообщения
остаются в программе, ASCII-команды запуска не зависят от кодировки. Файл `01-create-owner.cmd`
оставлен как необязательный инструмент для консоли при остановленном сервере.
Имя ZIP сохранено прежним для совместимости со ссылками; точная версия есть в `VERSION.txt`.

Полная [инструкция испытания](../docs/windows-test.md).
Проверка файла в PowerShell: `Get-FileHash .\club-prototype-0.1-win-x64.zip -Algorithm SHA256`.
Сравните результат с соседним файлом `.zip.sha256`.

Архив не содержит пользовательских данных и стандартных паролей.
Это версия учёта: блокировка Windows и завершение игр ещё не подключены.
Кросс-сборка выполнена в Linux; запуск на реальной Windows требует проверки.
